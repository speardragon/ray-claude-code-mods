# 📖 readability

**한국어** · [English](README.en.md)

Claude의 응답을 읽기 편하게 다시 그립니다. 본문은 또렷한 흰색, 제목은 `#` 표시와 구분선으로 크게, 인라인 코드와 링크는
눈에 띄게, 코드 블록은 테두리 상자와 구문 강조로, 표는 밝은 테두리로. 줄 폭은 기본 100칸으로 읽기 좋게 맞춥니다. 응답이 **스트리밍되는 동안에도** 같은 모습으로 그리고, 응답이
끝나는 순간 레이아웃이 튀지 않아요.

<img src="../../images/readability.png" alt="readability" width="100%">

## 왜 만들었나

[glamour-dark](https://github.com/Tickloop/claude-mods)에서 아쉬웠던 두 가지를 고쳤어요.

| 문제 | readability |
| --- | --- |
| 문장마다 줄을 나누고 위아래 여백을 넣어 오히려 산만함 | 엔진 기본 화면과 **같은 줄 흐름**(들여쓰기, 문단 사이 빈 줄 하나, 줄바꿈)을 유지하고 색과 강조만 더함 |
| 응답이 끝난 뒤에 한꺼번에 다른 레이아웃으로 바뀌어 "틱" 하고 튐 | 미완성 마크다운(닫히지 않은 코드 블록, 반쯤 온 표)도 안전하게 그려서 **그리는 즉시** 스타일 적용, 바뀌는 순간에도 줄 위치가 그대로 |

## 기능

- **본문**: 또렷한 흰색(`#f0f6fc`), 단어 단위 줄바꿈(한글은 글자 단위), 볼드는 더 밝게, 이탤릭, 취소선
- **제목**: 터미널은 글자 크기를 키울 수 없어서 레벨만큼 `#`을 붙이고, H1은 폭 전체 굵은 선, H2는 제목 아래 가는 선으로 크게 보이게
- **인라인 코드 · 링크**: 주황 + 옅은 배경 / 파란 밑줄(클릭 가능한 링크)
- **코드 블록**: 둥근 테두리 상자(위 테두리에 언어 라벨), 배경 패널, 구문 강조 (TS/JS, Python, Go, Rust, Shell, JSON, YAML 등)
- **표**: 밝은 테두리, 굵은 헤더, 정렬(`:---:`), 폭에 맞춰 셀 안에서 줄바꿈. `✅` 같은 이모지도 2칸으로 계산해 칸이 어긋나지 않아요
- **목록**: 단계별 색의 `•`, 번호 정렬, 체크박스 `☐` `☑`, 내어쓰기
- **인용**: `▌` 막대와 흐린 기울임

## 설치

```
/plugin install readability --marketplace speardragon/ray-claude-code-mods
```

## 사용법

| 입력 | 동작 |
| --- | --- |
| `/readability` | 켜기 / 끄기 (토글, 다음 세션에도 유지) |
| `/readability on` · `/readability off` | 켜기 · 끄기 |
| `/readability stats` | 이번 세션에 응답을 몇 번, 스트리밍 중에도 그렸는지 보기 |

## 설정

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `maxColumns` | `100` | 응답 줄 폭의 최대 칸 수. `0`은 터미널 전체 폭 |

## 알아두면 좋은 것

- 터미널에서만 동작해요. 데스크톱 · VS Code에서는 엔진 기본 화면 그대로입니다.
- 엔진이 스트리밍 중인 응답을 이 mod에 그리게 하는지는 Claude Code 버전에 따라 다를 수 있어요. `/readability stats`로
  확인할 수 있고, 엔진이 끝난 뒤에만 그리게 하면(2.1.311에서 확인), 그때 스타일이 입혀집니다. `maxColumns`를 `0`으로 두면 줄 폭까지 엔진과
  같아져서 바뀌는 순간 줄 위치가 거의 그대로예요.
- 요약 행(`· summary`)은 엔진의 표시를 지키기 위해 그대로 둡니다.
