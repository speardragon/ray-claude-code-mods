# 🗂️ diff-explorer

**한국어** · [English](README.en.md)

Claude가 이번 세션에서 바꾼 파일을 채팅 옆 패널에 VS Code처럼 보여줍니다. 왼쪽은 바뀐 파일만 모은 탐색 트리,
오른쪽은 고른 파일의 diff를 GitHub 다크 톤으로. 터미널을 떠나지 않고 "방금 뭐가 바뀌었지?"에 답할 수 있어요.

<img src="../../images/diff-explorer.png" alt="diff-explorer" width="100%">

## 기능

- **바뀐 파일 트리**: Material Icon Theme 스타일 아이콘과 폴더 색, VS Code의 git 상태 색(`M` 수정 · `A` 새 파일 · `D` 삭제).
  하나뿐인 하위 폴더는 `src/hooks`처럼 한 줄로 합칩니다.
- **GitHub 다크 diff**: 옛/새 줄 번호, 추가·삭제 배경, 짝지어진 줄에서 실제로 바뀐 글자만 진하게. 3줄 문맥과 `⋯ N unchanged lines`.
- **누적 diff**: 기준점은 Claude가 그 파일을 처음 건드리기 직전 내용이라, 여러 번 고쳐도 한 번에 보입니다. 원래대로 되돌린 파일은 흐리게 남아요.
- **새 파일 / 삭제**: `NEW`, `DELETED` 배지와 취소선.
- **파일 보기**: `v`로 diff와 구문 강조된 파일 전체 보기를 전환.
- **스크롤**: 트리와 미리보기가 각자 스크롤되고, 줄바꿈(`w`)을 끄면 가로 스크롤바와 `◀ ▶`로 옆으로 이동.
- **메인·서브에이전트 모두**: `Write` `Edit` `MultiEdit` `NotebookEdit`로 바뀐 파일을 잡습니다.

## 설치

```
/plugin install diff-explorer --marketplace speardragon/ray-claude-code-mods
```

## 사용법

| 입력 | 클릭할 곳 | 동작 |
| --- | --- | --- |
| `/diffs` | | 패널 열기 |
| `/diffs clear` | | 추적 기록 비우기 (지금 내용이 새 기준점) |
| `/diffs close` | | 패널 닫기 |
| `t` | 툴바 `Explorer` | 탐색기 접기 / 펴기 |
| `c` | 탐색기 제목 줄 오른쪽 | 폴더 모두 접기 / 모두 펴기 |
| `p` / `n` | 파일 헤더 `‹` `›` | 이전 / 다음 파일 |
| `v` | 상태줄 `Diff │ File` | diff ↔ 파일 전체 |
| `w` | 상태줄 `Wrap` | 긴 줄 줄바꿈 켜기 / 끄기 |
| `k` / `j` | 상태줄 `▲` `▼` | 한 화면 위 / 아래 |
| `h` / `l` | 상태줄 `◀` `▶` | 가로 스크롤 (줄바꿈을 껐을 때) |
| | 트리 줄 | 파일 고르기, 폴더 접기 / 펴기 |
| 휠 · 스크롤바 | | 커서가 올라간 컬럼만 스크롤, 스크롤바는 드래그 · 클릭 |

단축키는 패널 안(툴바, 트리, 헤더, 상태줄, 스크롤바)을 한 번 클릭한 뒤 동작합니다. 패널이 72칸보다 좁으면 트리가 자동으로
숨고, 파일 헤더의 `‹` `›`와 `현재/전체`로 이동해요.

## 설정

`/config`의 플러그인 항목에서 바꿉니다.

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `icons` | `nerd` | `nerd`: Nerd Font 글리프 아이콘. `plain`: 색 점, 어떤 폰트에서나 보임 |
| `autoOpen` | `true` | 세션의 첫 수정 때 패널을 자동으로 열기 (전체 화면 터미널에서 옆에 붙을 때만) |

## 알아두면 좋은 것

- `Bash`로 바꾼 파일(`sed -i`, `rm` 등)은 아직 추적하지 않아요. 단, 추적 중인 파일이 Bash로 지워지면 `DELETED`로 보입니다.
- 1 MB가 넘는 파일은 diff 대신 안내만 보이고, `v`로 파일 내용은 볼 수 있어요.
- 마우스 휠의 가로 이동은 Claude Code가 mod에 전달하지 않아서, 가로 스크롤은 스크롤바와 `h` `l`로 합니다.
