# diff-explorer

Claude가 이번 세션에서 수정한 파일을 채팅 옆 패널에 VS Code처럼 보여주는 mod입니다.
왼쪽에는 바뀐 파일만 모은 탐색 트리(Material Icon Theme 스타일 아이콘, git 상태 색), 오른쪽에는
선택한 파일의 diff가 GitHub 다크 테마 색으로 그려집니다.

- **기준점**: 세션에서 Claude가 그 파일을 처음 건드리기 직전 내용. 같은 파일을 여러 번 고쳐도 누적 diff로 보입니다.
- **추적 대상**: `Write`, `Edit`, `MultiEdit`, `NotebookEdit` (메인 에이전트와 서브에이전트 모두). Bash로 바꾼 파일은 아직 잡지 않습니다.
- **새 파일**은 `NEW`, **삭제된 파일**은 `DELETED` 배지와 취소선으로 표시됩니다. 원래대로 되돌아간 파일은 흐리게 남습니다.

## 설치

```
/plugin install diff-explorer --marketplace speardragon/ray-claude-code-mods
```

## 사용법

| 입력 | 클릭할 곳 | 동작 |
| --- | --- | --- |
| `/diffs` | | 패널 열기 (포커스까지) |
| `/diffs clear` | | 추적 기록 비우기 (지금 내용이 새 기준점) |
| `/diffs close` | | 패널 닫기 |
| `t` | 툴바 왼쪽 `Explorer` | 탐색기 접기/펴기 |
| `c` | 탐색기 제목 줄 오른쪽 아이콘 | 폴더 모두 접기 / 모두 펴기 |
| `p` / `n` | 파일 헤더 오른쪽 `‹` `›` | 이전 / 다음 파일 |
| `v` | 하단 상태줄 `Diff │ File` | diff ↔ 파일 전체 보기 (구문 강조) |
| `w` | 하단 상태줄 `Wrap` | 긴 줄 줄바꿈 켜기/끄기 |
| `k` / `j` | 하단 상태줄 `▲` `▼` | 미리보기 한 화면 위 / 아래 |
| `h` / `l` | 하단 상태줄 `◀` `▶` (줄바꿈 끔·파일 보기일 때) | 미리보기 가로 스크롤 |
| | 스크롤바 (트리·미리보기 세로, 미리보기 가로) | 드래그, 트랙 클릭으로 점프, 클릭 후 방향키·PageUp/Down·Home/End |
| | 탐색기 줄 | 파일 선택, 폴더 접기/펴기 (마우스를 올리면 은은한 배경) |
| 마우스 휠 | | 커서가 올라간 컬럼(트리 또는 미리보기)만 스크롤 |

모든 컨트롤은 마우스를 올리면 은은한 배경(`#262c36`), 누르는 동안 한 단계 진한 배경으로 바뀝니다.
단축키는 **패널 안(툴바·탐색기·파일 헤더·상태줄·스크롤바)을 한 번 클릭한 뒤** 동작합니다. 탐색기를 클릭한 상태에서는
`↑` `↓`로 파일을 이동하고, 다른 곳에서는 `↑` `↓` `PageUp` `PageDown` `←` `→`로 미리보기를 스크롤합니다.
패널이 좁으면(72칸 미만) 트리가 자동으로 숨고, 파일 헤더의 `현재/전체` 위치와 `‹` `›`로 이동합니다.

## 설정

`/config`의 플러그인 항목, 또는 settings의 `pluginConfigs.diff-explorer`:

- `icons`: `nerd`(기본, Nerd Font 글리프) 또는 `plain`(색 점, 아무 폰트에서나 보임)
- `autoOpen`: 세션에서 첫 수정이 생기면 패널을 자동으로 열지 (기본 `true`, 전체화면 터미널에서 사이드바로 붙을 때만)
