# 💬 prompt-history

**한국어** · [English](README.en.md)

이번 세션에서 내가 보낸 프롬프트만 모아 채팅 옆 패널에 보여줍니다. 언제 보냈는지 한눈에 보고, 긴 프롬프트도 전문으로
읽고, 버튼 한 번으로 트랜스크립트의 그 위치로 돌아가세요.

<img src="../../images/prompt-history-ko.png" alt="prompt-history" width="100%">

## 기능

- **날짜별 목록**: `오늘` · `어제` · `10월 20일 (월)` 구분선 아래 번호와 한 줄 요약(줄바꿈은 `↵`).
- **상대 시간**: `방금 전` → `3분 전` → `2시간 전` → `3일 전`, 일주일이 지나면 `10월 12일`. 30초마다 갱신되고, 시간이
  길어져도 줄 끝의 시간은 항상 보이게 프롬프트 쪽이 줄어듭니다.
- **전문 미리보기**: 고른 프롬프트를 오른쪽에 원문 그대로(단어 단위 줄바꿈). 길면 휠, 스크롤바, `↑` `↓`로.
- **복사**: `[ ⧉ 복사 ]`로 고른 프롬프트 전문을 그대로 클립보드에. 다시 보내거나 다른 데 붙여 넣을 때.
- **그 위치로 이동**: `[ ↗ 이동 ]` 버튼이나 `/prompts <번호>`로 트랜스크립트를 그 프롬프트까지 스크롤.
- **이전 프롬프트까지**: 켜질 때 세션 트랜스크립트에서 그동안 보낸 프롬프트를 읽어 오고, 이후엔 보내는 즉시 추가.
  슬래시 명령과 그 출력, 엔진이 끼워 넣는 메시지는 빠집니다. `/clear` 하면 비워져요.
- **한국어 / English**: 툴바의 `한국어 │ EN`으로 시간 표기를 바로 전환.

## 설치

```
/plugin install prompt-history --marketplace speardragon/ray-claude-code-mods
```

## 사용법

| 입력 | 동작 |
| --- | --- |
| `/prompts` | 패널 켜기 / 끄기 (토글). 켤 때 패널에 포커스가 가서 바로 `↑` `↓`로 고를 수 있어요 |
| `/prompts on` · `/prompts off` | 패널 켜기 · 끄기 |
| `/prompts 3` | 3번째 프롬프트 위치로 바로 이동 |
| `↑` `↓` | (패널에 포커스가 있을 때) 프롬프트 고르기, `PageUp` `PageDown`은 여러 개씩, `Home` `End`는 처음 / 끝 |
| `Enter` | (패널에 포커스가 있을 때) 고른 프롬프트 위치로 이동 |
| 목록 줄 클릭 | 그 프롬프트를 골라 오른쪽에 전문 표시 |
| `[ ⧉ 복사 ]` | 고른 프롬프트 전문을 클립보드에 복사 |
| `[ ↗ 이동 ]` | 고른 프롬프트 위치로 이동 |
| 상태줄 `▲` `▼` | 전문 한 화면 위 / 아래 |
| 휠 · 스크롤바 | 커서가 올라간 컬럼만 스크롤 |

## 포커스: 패널 ↔ 프롬프트 입력창

키 입력은 한 번에 한 곳으로만 갑니다. 프롬프트 입력창이거나, 패널이거나.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 패널로 가기 | `/prompts`로 켤 때 자동으로, 또는 `ctrl+x tab`, 또는 패널의 버튼 클릭 |
| 입력창으로 돌아오기 | `Esc` (패널은 그대로 열려 있어요) |
| 패널 닫기 | `/prompts` 다시 입력, `/prompts off`, 또는 `ctrl+x x` |

패널에 포커스가 있으면 `↑` `↓`가 목록을 움직이고 `Enter`가 이동 버튼을 누릅니다. 입력창에 포커스가 있으면 평소처럼
타이핑과 프롬프트 기록(`↑`)으로 동작해요.

## 설정

| 키 | 기본값 | 설명 |
| --- | --- | --- |
| `locale` | `ko` | `ko`(`3분 전`, `10월 22일`, `오후 2:31`) 또는 `en`(`3m ago`, `Oct 22`, `2:31 PM`). 툴바에서 세션 동안 바꿀 수 있어요 |

## 알아두면 좋은 것

- Claude Code는 사람이 직접 한 입력(버튼, 직접 친 명령)에 답할 때만 트랜스크립트를 움직입니다. 목록 줄은 호버를 직접
  그리는 영역이라 그 클릭으로는 이동하지 않고, 이동은 `[ ↗ 이동 ]`과 `/prompts <번호>`로 합니다.
- 시간대는 시스템(`date +%z`)을 따릅니다.
