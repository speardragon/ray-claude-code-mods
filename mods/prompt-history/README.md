# prompt-history

이번 세션에서 내가 보낸 프롬프트만 모아서 채팅 옆 패널에 보여주는 mod입니다. 파일 탐색기처럼 왼쪽에 목록,
오른쪽에 전문 미리보기가 있고, `[ ↗ 이동 ]` 버튼을 누르면 트랜스크립트가 그 프롬프트를 보냈던 위치로 이동합니다.

- **목록**: 날짜 구분선(오늘 / 어제 / 10월 20일 (월)), 번호, 한 줄로 자른 프롬프트(줄바꿈은 `↵`), 보낸 시각
  (방금 전 · 3분 전 · 2시간 전 · 3일 전, 일주일이 지나면 날짜).
- **미리보기**: 클릭해서 고른 프롬프트의 전문을 보여줍니다(처음엔 가장 최근 프롬프트). 마우스를 올리면 줄 배경만
  은은하게 바뀌고 미리보기는 그대로입니다. 긴 프롬프트는 휠·스크롤바·`↑` `↓`로 내려 볼 수 있습니다.
- **수집**: mod가 켜질 때 세션 트랜스크립트 파일에서 그동안 보낸 프롬프트를 읽고, 이후엔 보내는 즉시 추가합니다.
  슬래시 명령, 명령 출력, 엔진이 끼워 넣는 메시지는 빠집니다. `/clear` 하면 비워집니다.

## 설치

```
/plugin install prompt-history --marketplace speardragon/ray-claude-code-mods
```

## 사용법

| 입력 | 동작 |
| --- | --- |
| `/prompts` | 패널 열기 |
| `/prompts 3` | 3번째 프롬프트 위치로 이동 |
| 목록 클릭 | 그 프롬프트를 고르고 오른쪽에 전문 표시 |
| `[ ↗ 이동 ]` 버튼 | 고른 프롬프트 위치로 이동 (`ctrl+x tab`으로 포커스 후 Enter도 됨) |
| 목록 클릭 후 `↑` `↓` / `j` `k` | 프롬프트 고르기, `Home` `End`로 처음/끝 |
| 휠 | 커서가 있는 컬럼(목록 또는 미리보기)만 스크롤 |
| 툴바 `한국어 │ EN` | 시간 표기 언어 전환 |

Claude Code는 사람이 직접 한 입력(Button 누르기, 직접 친 명령)에 대한 응답일 때만 트랜스크립트를 움직입니다. 목록 줄은
호버 배경을 직접 그리는 영역(`Client`)이라, 그 클릭은 엔진이 사람 입력으로 인정하지 않습니다. 그래서 이동은
`[ ↗ 이동 ]` 버튼과 `/prompts <번호>`로 합니다. 이동이 거절되면 상태줄에 `⚠`와 이유가 표시됩니다.

## 설정

- `locale`: `ko`(기본, `3분 전`, `10월 22일`) 또는 `en`(`3m ago`, `Oct 22`). 툴바에서 세션 동안 바꿀 수 있습니다.
